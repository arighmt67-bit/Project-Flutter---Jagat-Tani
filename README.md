# JagatTani

JagatTani is a project for agricultural technology, featuring:
- AI-based Paddy Disease Classification.
- Fertilizer Recommendation System.
- Weather recommendation service.
- Integration with Google Gemini for agricultural advice.

## Tech Stack
- Flutter (Mobile App)
- TensorFlow Lite (Machine Learning)
- Python (Model Training)
- Firebase

## Project Structure
- `lib/`: Flutter application code.
- `ModelML_TanthyTW_RekomendasiPupukPadi/`: ML model training and assets.
- `model_training/`: Training scripts.
- `android/`, `ios/`, `linux/`, `macos/`, `web/`, `windows/`: Platform-specific code.

## How to run
1. Install Flutter.
2. Run `flutter pub get`.
3. Configure your API keys (Gemini, Firebase).
4. Run the app using `flutter run`.
